# LongHorizonsHack

Our entry for the Long Horizon Agents Hackathon (tokens&, San Francisco, September 2026).

**HorizonCraft** is a personal world builder: talk to an agent about your life and it builds a 3D world that mirrors the conversation, keeps it alive for hours, follows the real weather of the places you mention, and remembers you. The project lives in [`horizoncraft/`](horizoncraft/), which has the full README, setup steps and architecture.

Sponsor tools used: Liquid AI (LFM2, local), Nimble (live web data), Black Forest Labs (FLUX), Rawtree (analytics), fal.ai (Hunyuan3D hosting), OpenAI.
